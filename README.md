# ITI Summer Training — AI & Machine Learning Foundations (Level 1)

This repository contains my lab work and assignments from the **ITI AI & Machine Learning Foundations — Level 1** summer training track. Each file corresponds to a lab session, covering the progression from core Python fundamentals through NumPy/Pandas, exploratory data analysis, regression, classification, and neural networks.

## 📁 Contents

| File | Topic | Description |
|---|---|---|
| `Lab-1.py` | Python Basics I | Intro exercises: circle area, odd/even check, conditional sums, and other beginner-level programs. |
| `Lab-2.py` | Python Basics II | Unit conversions (inches→cm, °C→°F), sphere volume, and further foundational exercises. |
| `Lab-3.py` | Object-Oriented Programming | Class design exercises (e.g. a `Circle` class with `area()` and `perimeter()` methods). |
| `Lab-4.py` | NumPy — Part 1 | Array creation, element-wise tests (`isfinite`, `isinf`, `isnan`), boolean masking, and other core NumPy operations. |
| `Lab-4_Part-3.py` | NumPy — Part 3 | Vector operations (addition, subtraction, dot product) and matrix multiplication. |
| `Lab5_part1.ipynb` | Pandas & Statistics — Part 1 | Data loading, exploratory statistics, and plotting with `pandas`, `matplotlib`, and `scipy.stats`. |
| `Lab5_part2.py` | NumPy — Part 2 | Array aggregation exercises: min/max along axes, flattened arrays, and related NumPy tasks. |
| `lab_5.py` | Data Visualization | Sales data analysis and line-plot generation from `company_sales_data.csv` (exported from Colab). |
| `Lab6_part1.ipynb` | Exploratory Data Analysis — Part 1 | Loading and inspecting the Iris dataset (shape, dtypes, preview rows) and general EDA workflow. |
| `Lab6_Part2.ipynb` | Data Preprocessing — Part 2 | Feature scaling concepts (`StandardScaler` vs `RobustScaler`), mean vs. median, and evaluation-metric reasoning (precision/recall trade-offs), with bilingual (Arabic/English) notes. |
| `Lab7_SimpleLinearRegression.ipynb` | Simple Linear Regression | Three case studies: house price vs. size, exam score vs. study hours, and diabetes progression vs. BMI. |
| `Lab7_MultiVariableLinearRegression.ipynb` | Multivariable Linear Regression | Case studies on Boston Housing, Diabetes progression, and California Housing using multiple features. |
| `lab_8.py` | Classification — Logistic Regression | Breast cancer diagnosis: EDA, train/test split, logistic regression (with and without L2 regularization), grid search, and evaluation via confusion matrix, precision, recall, and ROC-AUC. |
| `Lab9.ipynb` | Classification & Regression Case Studies | Iris species classification (multiclass), diabetes progression (regression), and wine quality classification (imbalanced multiclass). |
| `MLP_Lab_9_ScikitLearn_vs_Keras.ipynb` | Neural Networks — Scikit-learn vs. Keras | MLP case studies solved with both `MLPClassifier`/`MLPRegressor` and Keras, including decision-boundary visualizations. |
| `MLP_Lab9_Full_Solutions.ipynb` | Neural Networks — Full Solutions | All 5 MLP case studies solved two ways (baseline vs. tuned architecture), with performance comparisons and takeaways. |
| `Lab10.ipynb` | Case Study — Boston Housing Regression | End-to-end regression case study on the Boston Housing dataset. |

## 🧠 Topics Covered

- Python fundamentals & OOP
- NumPy (array operations, linear algebra basics)
- Pandas & data visualization
- Exploratory Data Analysis (EDA) & preprocessing (scaling, outliers)
- Linear Regression (simple & multivariable)
- Classification (logistic regression, multiclass, imbalanced data)
- Model evaluation metrics (precision, recall, ROC-AUC, confusion matrix)
- Neural Networks / MLPs (Scikit-learn & Keras)

## 🛠️ Tools & Libraries

`Python`, `NumPy`, `Pandas`, `Matplotlib`, `SciPy`, `Scikit-learn`, `Keras`
