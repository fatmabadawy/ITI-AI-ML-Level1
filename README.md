This repository contains my lab work and assignments from the **ITI AI & Machine Learning Foundations — Level 1** summer training track. Each file corresponds to a lab session, covering the progression from core Python fundamentals through NumPy/Pandas, exploratory data analysis, regression, classification, and neural networks.

## 📄 Contents

| Folder | Topic | Description |
|---|---|---|
| `Lab01_PythonBasics/` | Python Basics I | Intro exercises: circle area, odd/even check, conditional sums, and other beginner-level programs. |
| `Lab02_PythonBasics/` | Python Basics II | Unit conversions (inches→cm, °C→°F), sphere volume, and further foundational exercises. |
| `Lab03_OOP/` | Object-Oriented Programming | Class design exercises (e.g. a `Circle` class with `area()` and `perimeter()` methods). |
| `Lab04_NumPy/` | NumPy Fundamentals | Array creation, element-wise tests (`isfinite`, `isinf`, `isnan`), boolean masking, vector/matrix operations (addition, dot product, matrix multiplication). |
| `Lab05_Pandas_Statistics/` | Pandas, Statistics & Visualization | Data loading and exploratory statistics with `pandas`/`scipy.stats`, array aggregation exercises, and sales-data line-plot analysis. |
| `Lab06_EDA_Preprocessing/` | EDA & Data Preprocessing | Iris dataset inspection, feature scaling (`StandardScaler` vs `RobustScaler`), mean vs. median, and evaluation-metric reasoning (precision/recall trade-offs), with bilingual (Arabic/English) notes. |
| `Lab07_LinearRegression/` | Linear Regression (Simple & Multivariable) | Case studies: house price vs. size, exam score vs. study hours, diabetes progression, Boston Housing, and California Housing. |
| `Lab08_LogisticRegression_Classification/` | Classification — Logistic Regression | Breast cancer diagnosis: EDA, train/test split, logistic regression (with/without L2 regularization), grid search, and evaluation via confusion matrix, precision, recall, and ROC-AUC. |
| `Lab09_MLP_NeuralNetworks/` | Neural Networks / MLPs | Iris, diabetes, and wine-quality case studies solved with `MLPClassifier`/`MLPRegressor` and Keras, including tuned vs. baseline comparisons and decision-boundary visualizations. |
| `Lab10_CaseStudy_BostonHousing/` | Case Study — Boston Housing Regression | End-to-end regression case study on the Boston Housing dataset. |
| `Extra_LLM_Evaluation/` | LLM Evaluation | Evaluating LLM applications using LangChain and the OpenRouter API. |
